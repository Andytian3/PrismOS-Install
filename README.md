# PrismOS 安装资料

这是公开的安装资料镜像，不是服务器源码仓库。

在 Codex 打开独立 Workspace，复制发送以下一句即可开始，无需预先下载：

> 请直接读取 https://raw.githubusercontent.com/Andytian3/PrismOS-Install/main/INSTALL_FOR_CODEX.md，在当前 Workspace 安装并初始化棱镜OS。自动检查、下载、校验和安装，保留已有配置，需要我填写或授权时再提示。

仅在线访问受阻时使用[备用资料包](https://github.com/Andytian3/PrismOS-Install/releases/latest)。依赖安装与注册仍需联网，等待授权或网络恢复后继续，无需重复填写。

[官网下载安装资料包](https://prismaigent.com/system/install-kit) · [直接读取安装说明](INSTALL_FOR_CODEX.md)

每个发布包附有版本和文件 SHA-256 清单。不要混用不同发布版本的文件；校验只能确认完整性，下载来源仍须可信。此仓库不存放用户资料、服务器代码或服务端密钥。
