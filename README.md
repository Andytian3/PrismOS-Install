# PrismOS 安装资料

这是公开的安装资料镜像，不是服务器源码仓库。

1. [下载完整安装资料包](https://github.com/Andytian3/PrismOS-Install/releases/latest)。
2. 解压到你在 Codex 中打开的独立 Workspace。
3. 让 Codex 读取包内 `INSTALL_FOR_CODEX.md`，先做离线检查并填写 `init-form.html`。
4. Python 依赖安装和 Workspace 注册仍需联网。授权等待或网络失败时保留配置，之后继续，无需重复填写。

[官网下载安装资料包](https://prismaigent.com/system/install-kit) · [直接读取安装说明](INSTALL_FOR_CODEX.md)

每个发布包附有版本和文件 SHA-256 清单。不要混用不同发布版本的文件；校验只能确认完整性，下载来源仍须可信。此仓库不存放用户资料、服务器代码或服务端密钥。
